# 🎭 Persona 5 Royal — Web Portfolio

Portfolio interaktif bertema Persona 5 Royal (P5R) dengan estetika otentik Atlus, dynamic DOM rendering 100% via TypeScript murni, procedural Web Audio API synthesizer, transisi comic slash, dan keyboard/mouse navigation ala Phantom Thieves.

![TypeScript](https://img.shields.io/badge/TypeScript-5.x-blue)
![Vite](https://img.shields.io/badge/Vite-5.x-purple)
![License](https://img.shields.io/badge/License-MIT-yellow)

## ✨ Fitur Utama

- 🃏 **Dossier & Status**: Bio, HP/SP vital bars, 5-axis radar stats.
- ⚔️ **Combat Skills**: Elemental affinity table & skill badges.
- 🏰 **Heists**: Portofolio proyek sebagai operasi Palace dengan Blueprint Modal.
- 🎴 **Confidants**: Jejak pengalaman kerja & kolaborasi bergaya kartu tarot Tarot (Rank 1 - MAX).
- ✉️ **Calling Card**: Form kontak bergaya surat ancaman Phantom Thieves + All-Out Attack finish!
- 🎵 **P5R Audio Systems**: Procedural audio synthesizer + soundtrack layer.

## 🚀 Menjalankan Proyek

```bash
# 1. Install dependencies
npm install

# 2. Jalankan dev server
npm run dev

# 3. Build untuk produksi
npm run build

# 4. Preview build
npm run preview
```
